    本文整理适合入门的官方教程，并配上两个独立编写、实际渲染过的例子。建议先完成一个最小动画，再尝试将导数定义可视化。

    整理：zeta2 · 资料核对日期：2026 年 11 月 13 日。 本文使用 Manim Community（ManimCE）；示例在本机 v0.19.2 实测，检索时官方 stable 文档显示 v0.22.1。代码采用两者共有的基础接口；本文没有在 v0.22.1 上重新渲染，不将它标为实测版本。

    三、先理解三个概念

    概念 在代码里的角色 本文中的例子
    Mobject 画面中的对象 正方形、圆、坐标轴、公式
    Animation 描述对象如何变化 创建、书写、形状变换
    Scene 组织对象与动画的时间顺序 一个继承 Scene 的类

    在场景的 construct() 方法中，self.add() 直接加入对象，self.play() 播放动画，self.wait() 保留观察时间。理解这三个层次后，写动画就可以从“先展示什么、接着改变什么”开始。参考：Manim’s building blocks。

    五、数学例子：割线怎样趋近切线

    考虑 f(x)=x2f(x)=x^2f(x)=x2，固定 P=(1,1)P=(1,1)P=(1,1)，让 Q=(1+h,(1+h)2)Q=(1+h,(1+h)^2)Q=(1+h,(1+h)2) 向 PPP 靠近。割线斜率是

    f(1+h)−f(1)h=(1+h)2−1h=2+h.\frac{f(1+h)-f(1)}{h} =\frac{(1+h)^2-1}{h} =2+h. hf(1+h)−f(1)​=h(1+h)2−1​=2+h.

    当 h→0h\to 0h→0 时，斜率趋近 222，所以在 x=1x=1x=1 处的切线为 y=2x−1y=2x-1y=2x−1。

    下面的动画中，蓝线是函数图像，黄色线组展示割线及横、纵向变化量，最后出现的绿线是精确切线。为了避免数值计算中除以零，动画只把 hhh 缩小到 0.080.080.08；此时割线斜率是 2.082.082.08，它仍然是近似值。动画展示趋势，极限结论由上面的代数计算给出。

    现象 建议先检查什么
    找不到 manim 命令 是否在项目目录中使用了 uv run manim

    七、一条适合数学学习者的练习路线

    下面是本文建议的练习安排，可按自己的 Python 基础调整：

    1. 图形与位置： 创建圆、直线、箭头，用 next_to()、to_edge() 组织画面。
    2. 变化与节奏： 练习 Create、Write、Transform，为重要结论留出停顿。
    3. 公式表达： 先呈现题目，再分步加入推导，避免一次堆满整个屏幕。
    4. 函数与参数： 改写本文导数例子，把固定点从 x=1x=1x=1 换成其他位置。
    5. 独立小作品： 选择一个定义或定理，用十几秒动画只解释一个关键想法，例如数列收敛、黎曼和或向量投影。
