    如果你想把数学作业、课程笔记或论文写得整齐，LaTeX 是值得学习的工具。初学时可以把目标定得具体一些：先做出一份中文数学笔记，包含标题、公式、定理、表格和自动编号，再逐步扩展。

    本文整理适合入门的在线课程，并给出一份可以直接复制编译的完整示例。整理：zeta2 · 资料核对日期：2026 年 11 月 13 日。 示例使用本机 TeX Live 2022 中的 XeLaTeX 实际编译；这个版本记录用于说明验证环境，不表示新安装时需要选择旧版。

    入门教程系列：系列归档 · LaTeX：数学排版 · Manim：数学动画 · Lean：形式化证明

    二、安装与环境配置（按系统选择）

    LaTeX 文档通常是一个 UTF-8 编码的 .tex 文本文件。我们在里面写内容和结构命令，再编译成 PDF。编辑器是写代码的地方，TeX 发行版提供实际排版所需的程序、宏包和字体，两者不要混为一谈。官方安装说明 列出了不同平台的选择。

    先按自己的情况选一条路线，不需要把表格里的软件全部安装：

    使用环境 本文采用的路线 完成后在哪里写文档
    想先在线试用 Overleaf，无须本地安装 浏览器里的项目编辑器
    Windows TeX Live 完整安装 随发行版安装的 TeXworks，或其他文本编辑器
    macOS 完整版 MacTeX “应用程序 → TeX”中的 TeXShop
    Ubuntu / Debian 系统软件源中的 TeX Live 相关包 文本编辑器与终端

    本文选择 XeLaTeX + ctexart 作为中文起点：ctexart 提供中文文章的常见排版设置；XeLaTeX 支持 Unicode 与现代字体。中文配置的具体说明见 Overleaf 中文排版教程 和 LearnLaTeX 中文语言特性。

    示例显式设置 fontset=fandol，使用 TeX 生态中的 Fandol 字体，避免依赖某台电脑特有的中文字体。若精简安装中缺少字体或 ctex，需要先通过发行版的包管理工具补齐。

    2.1 在线使用：Overleaf

    1. 打开 Overleaf，登录后进入项目列表。
    2. 选择 New Project → Blank Project，给项目起名，例如 latex-starter。
    3. 打开项目中的 main.tex，用下文“文档骨架”的整段代码替换默认内容。
    4. 点击项目左下角齿轮 Settings，进入 Compiler 选项卡，将编译器选择为 XeLaTeX。如果使用旧版界面，可在项目菜单的 Settings 中寻找 Compiler。
    5. 确认主文档是 main.tex，点击 Recompile。右侧出现中文标题和公式，就完成了第一次编译。
    6. 使用 PDF 预览区的下载功能保存结果；以后修改源码，再次编译即可。

    这个选择是按项目保存的，新建其他中文项目时也要检查编译器。设置入口以 Overleaf 官方编译器说明 为准。在线路线完成后，可以直接进入第三节，不需要执行下面的本地安装命令。

    2.2 Windows：安装 TeX Live

    1. 打开 TeX Live 官方下载页，下载 Windows 安装程序 install-tl-windows.exe。
    2. 双击运行，等待安装器解压并打开安装窗口。
    3. 初学建议选择 完整安装方案（scheme-full）；需要时通过 Advanced 查看安装方案。保留 TeXworks 编辑器，避免安装后还要另找编辑器。
    4. 安装目录使用默认的 C:\texlive\年份 即可。若自行修改，选择简单的英文路径；这里的“年份”由下载版本决定，不要照抄成一个目录名。
    5. 点击 Install，保持网络连接，等待文件下载和格式生成全部完成。完整安装体积较大，请以安装器显示的空间需求为准；进度较慢时不要仅凭窗口暂时不动就认定失败。
    6. 安装完成后，关闭原来的终端和编辑器。重新打开 PowerShell，执行后面的“检查安装”命令。开始菜单里的 TeX Live 分组可找到 TeXworks。

    安装器通常会把程序目录加入 PATH。若网络逐包下载很慢，官方同页还提供 install-tl-iso-windows.exe，先下载 ISO 再安装；任选一种安装方式即可。Windows 的路径配置与安装行为见 TeX Live Windows 官方说明。

    2.3 macOS：安装 MacTeX

    1. 打开 MacTeX 官方下载页，确认当前安装包支持自己的 macOS 版本，再下载 MacTeX.pkg。
    2. 双击 .pkg，按安装器提示阅读说明、确认选项并完成安装。本文使用包含 TeX Live 与图形工具的完整安装；精简的 BasicTeX 需要另行补包，不作为本教程的默认路线。
    3. 安装成功后，在 Finder 的 应用程序 → TeX 中打开 TeXShop。
    4. 新建文档，粘贴第三节的完整代码，以 UTF-8 编码保存为 main.tex。在 TeXShop 的排版引擎选择框中选 XeLaTeX，点击 Typeset（排版），查看生成的 PDF。
    5. 再打开一个新的“终端”窗口，执行下文“检查安装”中的版本检查命令，确认命令行也能找到编译器。

    三、认识文档的骨架

    这几部分分别负责：

    写法 作用
    \documentclass{...} 选择文档类，确定文档的总体结构
    \usepackage{...} 加载额外功能，通常写在导言区
    \begin{document} 之前 导言区，用来配置宏包、标题等
    \begin{document} 与 \end{document} 之间 实际正文
    \maketitle 输出已经设置的标题、作者和日期
    \section{...}、\subsection{...} 表达章节层级并自动编号

    正文里空一行表示新段落。不要用许多空格模拟缩进，也不要把每个段落结尾都写成 \\。结构命令和样式分开之后，文档更容易统一调整。基本文档组织可以继续阅读 Overleaf 快速入门。

    四、数学公式：先掌握三种环境

    行内与独立公式

    行内公式使用 \(...\)，例如 \(a_n=1/n\)；不编号的独立公式可以使用 \[...\]。在 .tex 文档中建议用这些 LaTeX 数学分隔符，不必沿用博客 Markdown 里输入公式的习惯。

    自动编号与引用

    equation 产生编号，\label 给它一个稳定的内部名字，\eqref 输出带括号的编号。插入新公式后，编号可以自动更新。~ 是不换行空格，让“公式”和后面的编号不容易被拆到两行。

    多行推导按等号对齐

    & 指定对齐位置，\\ 换到下一行；星号版本 align* 不编号。align 本身已经是数学环境，不要再把它包在 \[...\] 内。这里的 align 和 \eqref 来自 amsmath；其官方包页面和手册入口见 CTAN：amsmath。

    常见符号可以先从 \frac{a}{b}、\sqrt{x}、x_i、x^{n+1}、\sum_{k=1}^{n} 学起。多字符的上下标要用花括号分组；数学中的函数名宜写 \sin、\log，而不是直接输入普通字母。更完整的讲解见 LearnLaTeX：数学。

    七、报错时先检查这些地方

    现象 先检查什么
    中文无法显示，或出现字体相关错误 编译器是否为 XeLaTeX；ctex 与指定字体是否安装
    Undefined control sequence 命令是否拼错，相关宏包是否加载
    Missing $ inserted 是否把下标 _ 或其他数学语法写到了正文模式
    Environment ... undefined 环境名是否拼错，例如用了 align 却没加载 amsmath
    ?? 或未定义引用警告 标签名字、标签位置，以及是否完成了重复编译
    Overfull \hbox 行内内容是否太长；检查长公式、长网址和不可断行的内容

    正文中想显示百分号、下划线、井号和与号时，可以分别写 \%、\_、\#、\&；未转义的 % 会把后面的行内内容当成注释。

    处理错误时从日志中的第一个错误开始，一次只改一处，再重新编译。后面很多报错可能只是第一处错误引起的连锁反应。可以对照 LearnLaTeX：处理错误 学习判断诊断信息。

    八、接下来怎么练习

    建议先把一页自己已经写好的数学作业重新排版，再尝试增加内容：

    1. 修改完整示例中的平方展开式，检查公式与证明是否同步变化。
    2. 增加一个小节和一个定理，观察目录、定理编号和引用如何更新。
    3. 插入一张图片，学习 graphicx 与 figure；接着学习参考文献管理。
    4. 写长文档时再研究分文件组织、学校或期刊模板，避免一开始就修改复杂模板。

    LaTeX 可以帮助表达数学，Manim 可以把变化过程做成动画，Lean 可以检查形式化证明。你可以从同一个数学主题出发，分别练习这三种表达方式。
